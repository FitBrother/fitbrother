# M14 — Copy e Conformidade Legal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Centralizar toda a copy de metas/calorias num único arquivo, com uma blocklist de termos reservados por lei a nutricionista/médico no Brasil, verificada automaticamente em CI — e um componente `<GoalsDisclaimer />` pronto para os milestones seguintes (M16, M10) consumirem.

**Architecture:** Constantes vivem em `packages/shared` (única fonte, consumida por mobile e, futuramente, server). Um scanner puro e testável (`node:test`, sem framework novo) recebe uma lista de arquivos e devolve violações; um wrapper de CLI fino (`tsx`) faz a I/O real (percorrer `apps/mobile`, ler arquivos) e chama o scanner. O wrapper é encadeado no script `lint` já existente na raiz — sem tocar `.github/workflows/ci.yml`, CI passa a rodar o check automaticamente.

**Tech Stack:** TypeScript, Node.js `node:test`/`node:assert/strict` (built-in, sem dependência nova), `tsx` (já hoisted no monorepo via `apps/server`), React Native + NativeWind (componente mobile).

## Global Constraints

- Tipografia: **nunca** `font-medium`/`font-semibold`/`font-bold` em RN — usar `font-sans`/`font-sans-medium`/`font-sans-semibold`/`font-sans-bold`/`font-sans-extrabold` (CLAUDE.md regra 1).
- Cores só via token Tailwind/`lib/colors.ts` — nunca hex inline em JSX (CLAUDE.md regra 3).
- Ícones: `lucide-react-native` apenas (CLAUDE.md regra 8).
- Sem `<div>`/`<h1>` — só `View`/`Text`/`Pressable` (CLAUDE.md regra 9).
- ESLint roda com `--max-warnings 0`: **qualquer** warning (`no-console` fora de `warn`/`error`, `no-explicit-any`, `no-unused-vars`) quebra `npm run lint`. Todo código novo deve ser 100% limpo, não só sem erros.
- Blocklist exata (do spec, `docs/superpowers/specs/2026-07-14-onboarding-spec-original.md` Fase 6): `"prescrição"`, `"sua dieta"`, `"plano alimentar prescrito"`, `"recomendação médica"`.
- Termos permitidos (guia de redação, não enforced por lint): `"metas estimadas"`, `"estimativa"`, `"ferramenta de acompanhamento"`.
- Relativos dentro de `packages/shared` usam extensão `.js` no import mesmo apontando para `.ts` (convenção já usada em `packages/shared/src/index.ts` — `moduleResolution` residual de build via `tsc`).

- [ ] **Step 3: Implementar a função mínima pra passar**

Crie `scripts/legal-copy/scan.ts`:

```ts
export type ScannedFile = { path: string; content: string };
export type Violation = { file: string; line: number; term: string };

/** Função pura: não lê disco, só varre o conteúdo já carregado em memória. */
export function findBlocklistViolations(
  files: ScannedFile[],
  blocklist: readonly string[],
): Violation[] {
  const violations: Violation[] = [];

  for (const file of files) {
    const lines = file.content.split("\n");
    lines.forEach((lineText, index) => {
      const lowerLine = lineText.toLowerCase();
      for (const term of blocklist) {
        if (lowerLine.includes(term.toLowerCase())) {
          violations.push({ file: file.path, line: index + 1, term });
        }
      }
    });
  }

  return violations;
}
```

### Task 3: CLI de verificação + integração no `lint` da raiz

**Files:**
- Create: `scripts/check-legal-copy.ts`

**Interfaces:**
- Consumes: `findBlocklistViolations` e os tipos de `scripts/legal-copy/scan.ts` (Task 2); `LEGAL_BLOCKLIST` de `packages/shared/src/copy/goals.ts` (Task 1).
- Produces: processo CLI que sai com código 1 se houver violação, 0 se limpo — executado via `npm run lint:legal-copy`, encadeado em `npm run lint` (portanto coberto pelo job `lint-and-typecheck` do CI sem editar `.github/workflows/ci.yml`).

- [ ] **Step 1: Escrever o wrapper de CLI**

Crie `scripts/check-legal-copy.ts`:

```ts
import { readdirSync, readFileSync, statSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";
import { LEGAL_BLOCKLIST } from "../packages/shared/src/copy/goals.js";
import { findBlocklistViolations, type ScannedFile } from "./legal-copy/scan.js";

const __dirname = dirname(fileURLToPath(import.meta.url));
const SCAN_ROOT = join(__dirname, "..", "apps", "mobile");
const SOURCE_EXTENSIONS = [".ts", ".tsx"];
const IGNORED_DIR_NAMES = new Set(["node_modules", ".expo", "dist", "android", "ios", ".git"]);

function collectFiles(dir: string): ScannedFile[] {
  const files: ScannedFile[] = [];
  for (const entryName of readdirSync(dir)) {
    if (IGNORED_DIR_NAMES.has(entryName)) continue;
    const fullPath = join(dir, entryName);
    const stat = statSync(fullPath);
    if (stat.isDirectory()) {
      files.push(...collectFiles(fullPath));
    } else if (SOURCE_EXTENSIONS.some((ext) => entryName.endsWith(ext))) {
      files.push({ path: fullPath, content: readFileSync(fullPath, "utf8") });
    }
  }
  return files;
}

const files = collectFiles(SCAN_ROOT);
const violations = findBlocklistViolations(files, LEGAL_BLOCKLIST);

if (violations.length > 0) {
  console.error("Termos proibidos de copy legal encontrados em apps/mobile:\n");
  for (const violation of violations) {
    console.error(`  ${violation.file}:${violation.line} — "${violation.term}"`);
  }
  console.error(
    `\n${violations.length} violação(ões). Ver LEGAL_BLOCKLIST em packages/shared/src/copy/goals.ts — ` +
      "esses termos são reservados a nutricionista/médico no Brasil.",
  );
  process.exit(1);
}

console.error("OK: nenhum termo da blocklist de copy legal encontrado em apps/mobile.");
```

> Nota: a mensagem de sucesso usa `console.error` (não `console.log`) porque a regra `no-console` do ESLint da raiz só permite `warn`/`error`, e `npm run lint` roda com `--max-warnings 0` — `console.log` quebraria o próprio lint.
